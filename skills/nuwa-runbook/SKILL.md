# 女娲蒸馏产线（适配版）

把一个思维对象蒸馏成一个可复用的技能包。本 runbook 是系统绑定型技能：仅适用于本工作区的 manual-gates 门禁体系。

## 触发词

- 「蒸馏XX」/「把XX做成skill」/「造个XX技能」/「女娲」

## 硬规则（不可协商）

1. **先立项再动手**：蒸馏不是一次性对话动作，是一个 standard 轨项目，必须走 manual-gates 27 节点门禁。
2. **调研不落盘 = 没做**：所有调研笔记、来源清单必须写入 `06_演进记录/<项目名>/`。
3. **信息源黑名单**：知乎、微信公众号、百度百科、CSDN 不得作为唯一信源；引用必须能回溯到一手材料。
4. **一手信源占比 > 50%**：官方文档、原始论文、作者本人著作/演讲为一手；达不到就诚实降级——在产物里明确标注「本技能基于二手整理，未经一手验证」，禁止伪装成色。
5. **宁交 60 分诚实版，不交 90 分虚标版**：蒸馏对象的边界、不确定性、不适用场景必须写进 SKILL.md 的「诚实边界」一节。
6. **🔴 检查点是 owner 专属的**：遇到红线检查点必须停下等 owner 确认，不得自查自过。

## 流程：27 节点映射

按 `07_流程调研/nuwa-darwin-integration/03_接入工作流.md` 第四节的映射执行，关键节点：

| 蒸馏环节 | 门禁节点 | 要点 |
|---|---|---|
| 立项（选对象、定档位） | N4 | 声明改动类型=Capability，standard 轨 |
| 调研 | N10 | 一手信源清单+调研笔记落盘 |
| 基线评审 🔴 | N11 | 蒸馏对象的可蒸馏性判断，砍范围；🔴 停等 owner |
| 提炼（三重验证） | N12 | 提炼出核心模型/步骤/检查清单，每条标注出处 |
| 组装 SKILL.md | N16 | frontmatter（name/description 含触发词）+正文骨架 |
| 三项测试 | N18-N19 | 失效条件测试、反模式测试、独立评审 |
| 对抗评审 🔴 | N26 | 五问挑战，答辩通过才算完；🔴 停等 owner |
| 注册与发布 | N22-N25 | 复制进技能目录、验证索引出现、git 收官 |

门禁操作示例（可直接复制）：

```bash
# 查下一步该做什么
python "04_技能包/manual-gates/scripts/gate.py" strategy plan_next '{"project":"<项目名>"}'
# 提交节点验收（role 按节点映射：strategy/design/data_ai/planning/dev/qa/ops）
python "04_技能包/manual-gates/scripts/gate.py" dev submit_check '{"project":"<项目名>","node_id":16,"artifact_path":"<绝对路径>","passed":true,"notes":"..."}'
```

## 档位选择

两档都是 standard 轨项目，档位只收窄调研工作量、不改变门禁强度：

- **快速档**：3 个维度、≤5 个信源，适合单一小概念。
- **标准档**：6 个维度全面蒸馏，适合方法论/框架级对象。

## SKILL.md 产物骨架

```markdown
---
name: <技能名>
description: <一句话能力 + 触发词>
---
# <技能名>
## 触发词
## 何时用 / 何时不用
## 核心流程（分步，每步可执行）
## 检查清单
## 反模式黑名单
## 诚实边界（≥3 条：本技能不适用什么、哪里可能错、什么算失败）
## 参考来源
```

## 反模式黑名单

- ❌ 跳过立项直接开写 SKILL.md
- ❌ 只搜二手文章拼内容，不溯源一手
- ❌ 「调研过了」但没有落盘文件
- ❌ 诚实边界一节留空或写「暂无」
- ❌ 自评自过 🔴 检查点
- ❌ 把蒸馏产物写成宣传文案而非操作手册（禁用「赋能」「抓手」「闭环」类空话）

## 诚实边界

1. 本 runbook 是**系统绑定型**技能：依赖本工作区的 manual-gates 门禁脚本与目录结构，拿到别的环境不能直接跑。
2. 蒸馏质量上限取决于信源质量；对冷门主题，一手信源可能根本不存在，此时应降级产出并明确标注，而非硬造。
3. 本 runbook 不保证蒸馏产物「好用」——它保证产物「诚实、可溯源、经过对抗评审」。效果需在实际使用中迭代。

## 实证案例

`nuwa-distill-mckinsey` 项目（standard 轨 27/27 门禁通过，节点产出物落盘 25 份，N10/N16 产出物以 gate_report 台账为准）：以麦肯锡结构化思维为蒸馏对象，产出 `04_技能包/mckinsey-structured-thinking/`，含 quality_check.py 自检脚本。该项目一手信源占比实测 27% 未达标，产物已按硬规则 4 诚实降级标注——降级机制本身经过实战验证。
