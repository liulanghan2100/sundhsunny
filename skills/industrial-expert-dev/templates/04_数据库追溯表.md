# 数据库追溯表

## 生产记录主表

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| Id | TEXT/INTEGER | 是 | 主键 |
| StationName | TEXT | 是 | 工位 |
| DeviceId | TEXT | 是 | 设备 |
| RawData | TEXT | 是 | 原始数据 |
| ParsedData | TEXT | 否 | 解析后数据 |
| ProductCode | TEXT | 否 | 产品/配方 |
| BatchNo | TEXT | 否 | 批次 |
| Result | TEXT | 是 | OK/NG/Timeout/Error |
| ErrorCode | TEXT | 否 | 错误码 |
| StartTime | DATETIME | 是 | 开始时间 |
| EndTime | DATETIME | 否 | 结束时间 |
| DurationMs | INTEGER | 否 | 耗时 |
| Operator | TEXT | 否 | 操作员 |
| Remark | TEXT | 否 | 备注 |

## 审计日志表

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | INTEGER | 主键 |
| User | TEXT | 用户 |
| Action | TEXT | 动作 |
| Detail | TEXT | 详情 |
| CreatedAt | DATETIME | 时间 |

## 查询要求

- 按时间
- 按条码/序列号
- 按结果
- 按工位
- 按产品/批次
- 导出 CSV/Excel
