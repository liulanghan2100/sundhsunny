# UI 页面清单

| 页面 | 操作员可见 | 管理员可见 | 必备内容 |
|---|---|---|---|
| 运行监控 | 是 | 是 | 当前结果、设备状态、心跳、产量、OK/NG |
| 通讯配置 | 否 | 是 | IP、端口、串口、协议、地址映射 |
| 设备交互 | 是 | 是 | Start/Stop/Reset/Ready/Busy/Complete/ACK |
| 数据查询 | 是 | 是 | 时间、条码、结果、导出 |
| 报警事件 | 是 | 是 | 当前报警、历史报警、确认 |
| 操作日志 | 否 | 是 | 登录、配置、导出、复位、清理 |
| 参数/配方 | 否 | 是 | 保存、加载、导入、导出、版本 |
| 系统维护 | 否 | 是 | 备份、恢复、数据库清理、运行诊断 |

## UI 验收

- 菜单能切换真实页面。
- 按钮必须有事件。
- 配置保存后重启仍存在。
- 状态必须随流程变化。
- 查询必须来自数据库。
- 导出文件必须真实生成。
