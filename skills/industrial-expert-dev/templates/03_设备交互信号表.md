# 设备交互信号表

## 标准握手

```text
Ready
-> Start/Trigger
-> Busy
-> Data transfer
-> Complete
-> OK/NG/ErrorCode
-> ACK
-> Reset/Clear
```

| 信号 | 方向 | 类型 | 触发条件 | 清除条件 | UI 是否显示 | 日志是否记录 |
|---|---|---|---|---|---|---|
| SoftwareReady | 软件 -> PLC/设备 | Bool |  |  | 是 | 是 |
| DeviceOnline | 设备 -> 软件 | Bool |  |  | 是 | 是 |
| Heartbeat | 双向 | Bool/Word |  |  | 是 | 否 |
| Start | PLC/软件 -> 设备 | Bool |  |  | 是 | 是 |
| Stop | PLC/软件 -> 设备 | Bool |  |  | 是 | 是 |
| Reset | PLC/软件 -> 设备 | Bool |  |  | 是 | 是 |
| Busy | 设备 -> 软件 | Bool |  |  | 是 | 是 |
| Complete | 设备 -> 软件 | Bool |  |  | 是 | 是 |
| OK | 设备/PLC -> 软件 | Bool |  |  | 是 | 是 |
| NG | 设备/PLC -> 软件 | Bool |  |  | 是 | 是 |
| ErrorCode | 设备/PLC -> 软件 | Word/Text |  |  | 是 | 是 |
| ACK | 软件 -> PLC/设备 | Bool |  |  | 是 | 是 |
