# 工业软件标准能力清单

## 调研摘要

成熟工业软件、SCADA、MES、追溯系统和设备集成工具通常围绕以下能力建设：

- 设备通讯：协议、地址、超时、重连、心跳。
- 状态监控：在线、离线、忙碌、就绪、报警、最近交互时间。
- 报警事件：实时报警、历史报警、确认、原因码。
- 历史数据：生产记录、过程数据、操作日志、事件日志。
- 权限审计：操作员、工程师、管理员，关键操作留痕。
- 报表导出：CSV、Excel、按时间/批次/工位统计。
- 配方参数：保存、加载、版本、导入导出、备份恢复。
- HMI 可用性：运行页清楚，配置页隔离，报警醒目，状态不可隐藏。

## 工业项目默认必备项

| 模块 | 最低要求 |
|---|---|
| 通讯配置 | IP、端口、串口、协议、地址映射可配置 |
| 通讯状态 | 在线、离线、心跳、最后交互时间可见 |
| 设备交互 | Start/Stop/Reset/Ready/Busy/Complete/ACK |
| 数据库 | 原始数据、结果、时间、工位、操作员入库 |
| 查询 | 时间、编号、结果、工位 |
| 导出 | CSV 最低要求 |
| 权限 | 管理员保护关键配置 |
| 审计 | 配置、导出、复位、删除必须记录 |
| 报警 | 超时、离线、NG、数据库失败 |
| 发布 | EXE、运行说明、验证记录、备份 |

## 设计红线

- 不允许只有静态 UI。
- 不允许配置输入框不持久化。
- 不允许按钮无事件。
- 不允许只保存日志、不显示查询入口。
- 不允许未测试真实协议却声称已完成真机适配。
- 不允许没有验收矩阵就开工。
