### 过程中发现并固化的两个工具坑

| 坑 | 现象 | 规避规则 |
|---|---|---|
| `gate_check.ps1` 的 `-DocPaths` 只接受相对路径 | 传绝对路径时脚本内部 `Join-Path $project $doc` 拼接出非法路径,所有文档静默报 `missing`,门禁假失败 | 调用方一律传项目相对路径;建议在项目内放 `run_gate.ps1` 包装脚本统一调用 |
| 含中文路径/中文文件名的 `.ps1` 必须带 UTF-8 BOM | 无 BOM 时 PowerShell 5.1 按 ANSI(GBK) 解码,中文路径变乱码,脚本内路径全部失效 | 任何含中文的 ps1 落盘时加 BOM;Git Bash 下可用 `printf '\xEF\xBB\xBF' > f.ps1 && cat src >> f.ps1` |

### 门禁复跑方式

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "08_实战项目\vision-inspection-station\run_gate.ps1"
```
