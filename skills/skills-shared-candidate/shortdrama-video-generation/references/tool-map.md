# AI Video Generator Tool Map

Use current official documentation or product pages before making final claims.

## Common Categories

### Cinematic Foundation Models

- OpenAI Sora: high-end text/image/video-to-video generation in OpenAI surfaces where available.
- Google Veo / Flow: strong cinematic generation and prompt following, with Google AI plan availability varying by region.

### Creator Production Suites

- Runway: strong editor workflow, image/video references, style and shot iteration.
- Luma Dream Machine / Ray: fast text/image-to-video exploration and camera motion.

### Social and Short-Clip Generators

- Kling AI: strong motion and image-to-video for short clips.
- Pika: fast stylized clips, effects, and social-video iteration.
- MiniMax Hailuo: fast prompt-to-video and character/action tests.

## Selection Heuristics

- For character consistency: image-to-video plus reference images.
- For action and martial movement: generate short 3-5 second clips, never one long scene.
- For dialogue drama: produce clean visuals first, add voice and subtitles in edit.
- For fantasy scenes: create location keyframes first; then animate with restrained camera motion.
- For IP adaptation: avoid copying existing film/animation/game visual designs unless licensed.

## Deliverable Recommendation

For a 10-minute episode:

- 8-12 recurring character references;
- 6-10 recurring location references;
- 80-140 shot rows;
- 3-8 second generated clips;
- external editing timeline;
- subtitle and audio pass;
- continuity QA sheet.
