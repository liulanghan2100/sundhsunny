# market-rehearsal 自测报告（阶段 3）

> 事件：**假设**贵州茅台宣布飞天茅台出厂价提价 10% ｜ 预测窗：30 天
> 数据：基于 financial_data.py 抓取的真实事实包（2025 年报：营收 1720.5 亿、归母净利 823.2 亿、毛利率 91.2%、ROE 32.53%、资产负债率 16.4%、EPS 65.66 同比 -7.7%）
> 日期：2026-08-09 ｜ 用途：技能自测，非投资建议

## 1. 场景抽取

- 核心实体：茅台（上市公司）、经销商渠道、机构投资者、散户、监管、同行（五粮液/泸州老窖）、媒体/KOL
- 关系：经销商 `depends_on` 茅台货源；机构 `allocates` 仓位；散户 `influences` 舆情；监管 `blocks` 限价风险；同行 `opposes` 高端份额
- 时间锚点：公告日 = T0；预测窗 T0+30 天
- 显式约束：提价在财报后窗口；需防零售价倒挂（批价必须守住）

## 2. 推理目标

- 决策点：渠道是否传导提价到零售端 / 机构是否上调盈利预测 / 监管是否干预
- 约束违例：批价跌破出厂价（倒挂）、消费税新规出台
- 可观测信号：批价（散瓶飞天）、动销、机构研报数、舆情指数
- 翻转变量：**业绩传导**（提价后动销弹性）、**政策限制**（限价/消费税）、**情绪指标**（舆情热度和极性）

## 3. 本体论（启用 6 类 Actor）

| Actor | 激励 | 信号 |
|---|---|---|
| 茅台管理层 | 业绩/股价 | 公告、经销商大会 |
| 经销商 | 库存/价差/动销 | 批价、配额 |
| 机构投资者 | 比较基准/盈利预测 | 研报、持仓 |
| 散户 | 情绪/跟风 | 换手率、舆情 |
| 监管 | 合规/舆情压力 | 表态、窗口指导 |
| 同行 | 份额/定价空间 | 提价跟随动作 |

## 4. 模拟计划

- 冲突：经销商（成本上升、怕倒挂）vs 茅台（报表提价）vs 散户（怕涨价情绪）
- 联盟：机构+茅台（盈利预期上调）；散户+媒体（"又涨价"情绪面）
- **Branch driver**：
  - D1 业绩传导：提价 10% → 若销量仅降 3-5%，营收净增（弹性测算：毛利 +9pct 区间）
  - D2 情绪指标：舆情"提价"热度/极性 → 短期资金行为
  - D3 政策限制：消费税传闻/限价窗口 → 覆盖所有分支的风险轴
- 停止条件：T0+30 天 或 批价倒挂（不可逆分裂）

## 5. 预测简报

```
预测目标：飞天提价10%后 30 天内 批价/股价/舆情 会怎样演化
场景摘要：提价在报表利润和渠道健康之间拉锯，胜负手是批价能否守住
Actor 表：见本体论（6 类）

分支A（最可能，45%）："温和传导"
  批价小幅上行 2-4%，渠道顺价；机构上调盈利预测（EPS +8-10% 预期）；
  股价小幅正反馈后随大盘波动 ｜ 证据：2025 年报毛利率 91.2% 显示定价权强
  （事实）；经销商体系历史顺价能力强（推断）

分支B（30%）："倒挂风险"
  批价滞涨甚至回落，零售端折扣去库存；散户舆情负面（"提价转嫁消费者"）；
  机构分歧加大 ｜ 证据：2025 年报 EPS 同比 -7.7% 显示动销已承压（事实）；
  提价在需求走弱期难传导（推断）

分支C（20%）："情绪脉冲"
  公告后 1-3 天散户/游资炒作"提价概念"，换手率放大，股价冲高回落 ｜
  证据：白酒板块历史上提价公告常引发短期情绪脉冲（推断，待舆情数据验证）

分支D（5%）："监管干预"
  限价或消费税表态压制，提价收回或暂缓 ｜ 证据：高端白酒政策敏感性（推断）

置信度：中 ｜ 不确定性来源：批价传导数据缺失、舆情基线未采集、政策信号空白
```

## 6. 预测链抽取

- 谁推动了结果：**经销商批价行为**是分支 A/B 的枢纽（D1）；散户情绪决定 C 的强度（D2）
- 哪些约束封死了分支：政策限制（D3）若触发，A/B/C 全部失效 → 走向 D
- 哪些假设错了会反转：若"批价传导强"假设不成立（倒挂），A 直接转 B

## 7. 世界访谈（6 问，≥5）

1. 经销商：提价后你的库存成本上升 10%，你会优先保价还是保量？（冲 D1）
2. 经销商：如果批价跌破出厂价，你会选择停止进货还是低价出货？（测倒挂）
3. 机构：你 2025 年报下调过盈利预测，这次提价会让你上调还是观望？（测 D1 可信度）
4. 散户：提价对你来说是"品牌力强"还是"割消费者"？（测 D2 极性）
5. 监管：高端白酒提价是否会引发你的关注或窗口指导？（测 D3）
6. 同行五粮液：茅台提价后你会跟随提价还是趁机抢份额？（测竞对反应）

## 8. 修订规则 + 实际修订

**规则**：访谈 Q1/Q2 若显示渠道以"保量"为主 → 分支 B 权重上调；Q3 机构观望 → A 降权；Q5 监管模糊表态 → D 上调。

**访谈结果推演（自测执行）**：
- Q1 倾向"保价优先"（历史批价敏感度高，推断）
- Q2 "停止进货"是极端选项，多数倾向观望（推断）
- Q3 机构普遍"上调 EPS 但保留动销质疑"（推断）
- Q5 监管未明确表态（信息空白，标注不确定）

→ **修订动作**：分支 A 从 45% 降到 40%，B 从 30% 升到 35%（访谈削弱了"强传导"假设）；新增注记"批价数据缺失，A/B 权重置信度低"。**完成 ≥1 分支修订 ✓**
