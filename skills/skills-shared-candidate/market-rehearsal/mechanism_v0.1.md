## 一、流程骨架（10 项，全部保留）

| # | 步骤 | 输入 | 输出 |
|---|---|---|---|
| 1 | 场景抽取 | 种子材料（新闻/财报/政策/传闻） | 核心实体 + 关系 + 时间锚点 + 显式约束（只留能改变结果的） |
| 2 | 推理目标识别 | 场景 | 决策点 / 约束违例 / 可观测信号 / 分支驱动变量 |
| 3 | 本体论设计 | 场景+目标 | 实体类型（含义/与近邻区别/证据/能力）+ 关系类型（方向/含义/可观测-推断-假设分级） |
| 4 | 模拟计划（离线） | 本体论 | 角色激励 / 记忆范围 / 冲突联盟 / 2-3 个翻转变量 / 停止条件 |
| 5 | 预测简报 | 模拟计划 | 预测目标 / 场景摘要 / 关键实体关系 / 最可能轨迹 / 备选分支 / 置信度与警告 / 每条主张证据 |
| 6 | 预测链抽取 | 简报 | 谁的行动推动了结果 / 哪些约束封死分支 / 哪些假设错则反转预测 |
| 7 | 世界访谈（反事实） | 简报 | ≥5 个问题：动机/约束/联盟/冲击反应/公开声明 vs 私利；冲突=信号 |
| 8 | 修订规则 | 访谈结果 | 分支权重调整的显式规则（访谈后至少 1 分支被修订） |

前置：本体论质量门（每个主要 actor 都有位置 / 关系类型够具体 / 重复概念合并 / 足够小可模拟）。
模拟设计质量门（见下）。

## 二、质量门（7 项，全部保留）

Q1 预测的具体结果是什么？
Q2 哪些 agent 在该结果上有冲突激励？
Q3 哪 2-3 个信号翻转会改变结果？
Q4 如何检测稳定收敛或不可逆分裂？
Q5 什么场景不适合本技能？
Q6 计划能否产出至少 3 条有意义分支？
Q7 简报能否用证据支撑每条分支？

## 三、离线输出最低质量线（强制）

- 简报 ≥3 条分支
- 访谈 ≥5 个问题
- 至少 1 条分支在访谈后修订
- 最终输出区分 事实 / 推断 / 不确定性

## 四、诚实边界（保留并强化）

- 无后端时不编造 API/调用（原版规则保留）
- **新增红线（阶段 2 强化）**：预演 ≠ 预测；不构成投资建议；不实盘下单；分支必须带证据

## 五、待改造项（→ 阶段 2）

1. Actor 模板：通用社会 actor → A股利益方模板（上市公司/大股东/机构/散户/经销商/监管/同行/媒体）
2. Branch driver 模板：执法力度类 → 业绩传导/库存消化/政策限制/情绪/流动性
3. 命名与触发：场景「市场反应预演」专属
4. 与 debate-protocol 分工：它管"该不该"，本技能管"会怎样演化"
