# task_queue_mcp

v5.16 local task queue and daemon-runner core for Manual Agent OS.

It runs only in user space and does not request local administrator privileges.

Tools:

- `queue_brief`
- `enqueue_task`
- `queue_status`
- `task_status`
- `run_next_task`
- `run_queue`
- `retry_task`
- `export_queue_report`
