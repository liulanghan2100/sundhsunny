# mathematical-reasoning-mcp

v6.33 adds executable mathematical reasoning primitives for Agent OS decisions.
It records local decision evidence and does not call external APIs.

Tools:

- `mathematical_reasoning_brief`
- `bayesian_update`
- `score_expected_value`
- `rank_information_gain`
- `build_dependency_graph`
- `detect_metric_anomaly`
- `simulate_project_risk`
- `reasoning_report`
