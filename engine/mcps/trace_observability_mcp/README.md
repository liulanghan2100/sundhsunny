# trace_observability_mcp

Records execution traces for the AI manual system.

Default storage:

```text
09_投研/trace_observability/<project>/trace.jsonl
```

Primary tools:

- `start_trace`
- `end_trace`
- `start_span`
- `end_span`
- `record_event`
- `trace_report`
- `project_trace_stats`
- `export_trace`
